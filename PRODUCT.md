# Product

## Register

product

## Users

Elysium serves visitors who browse, inspect, and download high-resolution wallpaper, plus internal administrators who curate the catalog. Admins work in focused content-management flows: ingest source assets, review technical metadata and provenance, organize categories and tags, and publish only approved drafts.

## Product Purpose

Elysium is a premium, high-resolution wallpaper library built for fast discovery without compromising original-file integrity. It separates lightweight preview delivery from untouched originals, keeps metadata authoritative in D1, and uses a simple Cloudflare architecture that can grow with the catalog.

## Brand Personality

Premium, cinematic, restrained. The interface should feel editorial and confident while remaining quiet enough for artwork and operational status to stay dominant.

## Anti-references

Avoid dense generic dashboards, decorative chrome, intrusive badges, aggressive gradients, excessive animation, and interfaces whose visual treatment competes with the wallpaper. Avoid unfamiliar controls where established admin patterns communicate the workflow more clearly.

## Design Principles

1. Artwork remains the visual subject; interface elements support selection and review.
2. Preserve source integrity and provenance at every step.
3. Make system state explicit, especially drafts, duplicates, failures, and irreversible actions.
4. Keep common admin workflows familiar, efficient, and keyboard accessible.
5. Prefer preview-first performance and minimal client-side work.

## Accessibility & Inclusion

Meet the project's stated baseline: keyboard navigation, visible focus states, sufficient contrast, semantic HTML, useful image alternatives, proper button semantics, and reduced-motion support. Status must never rely on color alone.
